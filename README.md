# Half Grip Multiplayer

BepInEx multiplayer mod for **Half Grip Demo**.

## Install (players)

1. Download **[HalfGripMultiplayer-0.9.0-game-root.zip](https://github.com/SildomLandor/half-grip-ai-mulitplayer/raw/feature/0.4.0-lobby-sync/dist/HalfGripMultiplayer-0.9.0-game-root.zip)**
2. Unpack it into the game folder (next to `HalfGrip.exe`). Overwrite if asked.
3. Launch the game. **F6** overlay · **F7** Steam host · **F8** leave.

Already have BepInEx? Use the smaller [plugin-only zip](https://github.com/SildomLandor/half-grip-ai-mulitplayer/raw/feature/0.4.0-lobby-sync/dist/HalfGripMultiplayer-0.9.0-plugin-only.zip) the same way.

Money, shop, and loadout stay **per-player**.
